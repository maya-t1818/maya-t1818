# こんにちは、竹内麻耶です 👋

COACHTECH でフルスタックWeb開発を学習中のweb系エンジニア志望です。  
ユーザ目線で考えてサービスを作ることに興味があります。  
初めての業界で、自分の書いたコードでウェブが動くことに感動を覚えました。

## 🛠️ 使える技術

- **バックエンド**: PHP / Laravel
- **フロントエンド**: HTML5 / CSS / Blade
- **データベース**: MySQL
- **その他**: Docker / Git・GitHub
